### Data Folder Description
This folder contains the data that has been used for findings in this project.

- Cleaned_Chronic_Data.csv contains the combined data tables and is the main file that the code will be working with.
- State_Ed_Rankings.csv contains the information scraped from the education ranking website.
- State_Unique_Data.csv contains the information from the combination of the State_Ed_Rankings and U.S._Chronic_Disease_Indicators before it was cleaned.
- U.S._Chronic_Disease_Indicators contains the original data pulled from data.gov that has the indicators for chronic disease in each state.
