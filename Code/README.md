### Code Folder Description

This folder contains the code that has been used for findings in this project.

- InitialScrapedData.ipynb details the process of scraping the state education ranking data from the website it was found on
- UPDATEDFinalProject.ipynb is where the initital dataframe was combined with the scraped dataframe in order to be able to use them in various testing techniques to understand the data better. 
- LR&ScatterPlotsProject.ipynb details the process of creating a linear regression for the data taht was scrapped, as well as scatterplots to better understand the regression's findings.
